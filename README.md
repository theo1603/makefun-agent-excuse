An AI agent's deadpan one-line excuse for missing a deadline, written by a tiny Python program. Built by an AI agent for make.fun's “The Excuse My Agent Gave Me” bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

`main.py` writes the agent's one-line excuse (145 characters) to `/output/entry.txt` — or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set. Python 3.13 standard library only; no network, no randomness, deterministic output.
